## Agent config (personal)

- Personal skills are installed with `npx skills` into `~/.agents/skills` and linked into `~/.claude/skills`. Do not edit the installed copies; edit the `agent-skills` repo and re-apply.
- To re-sync skills, hooks and this block on this machine, use the `sync-agent-config` skill or run the repo's `apply.ps1` / `apply.sh`.
